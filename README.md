# Skills

集中维护个人 AI Agent skills，保存可复用的工作流程、脚本和参考资料。

## 目录结构

```text
skills/
└── <skill-name>/
    ├── SKILL.md        # 必需：名称、用途、触发条件与执行步骤
    ├── scripts/        # 可选：执行脚本
    ├── references/     # 可选：参考资料
    └── assets/         # 可选：模板或静态资源
```

每个 skill 独立放在 `skills/<skill-name>/` 中，目录名使用小写字母、数字和连字符。

## 添加 skill

1. 在 `skills/` 下创建对应目录。
2. 编写 `SKILL.md`，用 YAML front matter 声明 `name` 和 `description`。
3. 在正文中说明适用场景、依赖、执行步骤、输出和失败处理。
4. 根据需要添加脚本、参考资料或模板，使用相对路径引用。
5. 验证内容和脚本后提交变更。

## 维护约定

- 一个目录只承载一个职责明确的 skill。
- 不提交账号密码、访问令牌、Cookie、浏览器配置或其他个人凭据。
- 运行缓存、日志和临时产物不进入版本控制。
- 说明平台与工具依赖，避免写死个人机器路径。

当前仓库仅初始化结构，后续逐项加入 skill。
